# Contributing to CLT Tools

Thank you for your interest in contributing to **CLT Tools**!

## Educational & Academic Collaboration
CLT Tools was initiated as a Master's Thesis research project (TFM) at **MArqUA - Universidad de Alicante**. We welcome contributions, bug reports, feature suggestions, and academic feedback from students, researchers, and engineers.

## How to Contribute

### Reporting Issues
- Use [GitHub Issues](https://github.com/josebernaf/CLT_Tools/issues) to report bugs or request new features.
- Please provide detailed steps to reproduce the issue, including Rhino and Grasshopper versions, OpenSees version, and relevant error messages from the component log.

### Pull Requests
1. Fork the repository.
2. Create a new branch for your feature or bug fix:
   ```bash
   git checkout -b feature/my-feature
   ```
3. Implement your changes following C# coding conventions used across the project.
4. Ensure the project builds cleanly without warnings:
   ```bash
   dotnet build CLT_Tools.csproj
   ```
5. Commit your changes and push to your fork.
6. Submit a Pull Request describing your modifications and test results.
